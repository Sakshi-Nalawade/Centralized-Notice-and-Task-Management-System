# Centralized Notice and Task Management System for Bank

A web-based application designed to centralize bank notices, circulars, employee communication, and administrative operations through a single platform.

## About the Project

The Centralized Notice and Task Management System for Bank provides a common platform for administrators and employees to access important notices, manage information, and perform various administrative activities efficiently.

The system aims to reduce manual communication and improve information accessibility within the banking environment.

## Features

- **User Authentication:** Secure login and role-based access for administrators and employees.
- **Notice Management:** Add, edit, manage, and publish important notices and circulars.
- **News and Updates:** Centralized display of organizational updates.
- **Policy Management:** Upload and manage bank policies and related documents.
- **Inward and Outward Management:** Maintain inward and outward records.
- **Fixed Asset Management:** Manage fixed assets and transfer approvals.
- **IT Asset Management:** Track IT assets and their transfer records.
- **User Management:** Manage employee accounts and profiles.
- **Photo Gallery:** Display organizational events and activities.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Code Editor:** Visual Studio Code

## Installation and Setup

1. Install XAMPP on your system.
2. Clone this repository:

   ```bash
   git clone https://github.com/Sakshi-Nalawade/Centralized-Notice-and-Task-Management-System.git
   ```

3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Create the required MySQL database using your project's database schema.
6. Configure the database connection in the project's configuration file.
7. Open the application in your browser:

   ```text
   http://localhost/Centralized-Notice-and-Task-Management-System/
   ```
